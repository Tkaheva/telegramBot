# 🌱 Telegram Habit Tracker Bot

Телеграм-бот для отслеживания привычек: помогает добавлять ежедневные дела, отмечать их выполнение, следить за сериями и видеть прогресс за неделю и месяц.

## ✨ Возможности

- ➕ **Добавление привычек** — с названием и (опционально) временем напоминания.
- ☑️ **Чек-лист на сегодня** — отметка привычек в один тап через inline-чекбоксы.
- 📊 **Статистика** — текущая серия, рекорд, выполнения за 7 и 30 дней.
- 🗓 **Карта недели** — визуальная сетка `Пн–Вс` со статусами всех привычек.
- 🌙 **Итоги дня** — сводка по выполненным и пропущенным делам за сегодня.
- 🗑 **Удаление привычек** — через команду `/del` или кнопку в чек-листе.
- 💾 **Сохранение данных** — всё хранится в `habits_data.json`, привычки автоматически переносятся на следующий день до удаления пользователем.
- 🔁 **Автономность** — после перезапуска бота данные полностью восстанавливаются.


## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Tkaheva/telegramBot.git
cd telegramBot
```

### 2. Установка зависимостей

Убедитесь, что у вас **Python 3.10+**.

```bash
pip install -r requirements.txt
```

Если файла `requirements.txt` ещё нет, создайте его с содержимым:

```txt
aiogram>=3.4,<4
```

Или установите вручную:

```bash
pip install "aiogram>=3.4,<4"
```

### 3. Получение токена бота

1. Откройте Telegram → найдите [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и username.
3. Скопируйте выданный токен вида `1234567890:AA...`.

**Никогда не коммитьте токен в репозиторий.** Храните его только в переменной окружения или в файле `.env`, который добавлен в `.gitignore`.

### 4. Запуск бота

**Windows (PowerShell):**
```powershell
$env:BOT_TOKEN="ваш_токен_от_BotFather"
python win.py
```

**Windows (CMD):**
```cmd
set BOT_TOKEN=ваш_токен_от_BotFather
python win.py
```

**Linux / macOS:**
```bash
export BOT_TOKEN="ваш_токен_от_BotFather"
python win.py
```

В консоли появится:
```
INFO:aiogram.dispatcher:Start polling
```

Бот готов — откройте его в Telegram и отправьте `/start`.



## Команды бота

| Команда | Описание |
| `/start` | Приветствие и главное меню |
| `/help` | Справка по командам |
| `/habits` | Добавить новую привычку (пошаговый диалог) |
| `/list` | Чек-лист на сегодня — отмечайте привычки нажатием |
| `/check` | Алиас для `/list` |
| `/stats` | Серия, рекорд и общая статистика по каждой привычке |
| `/map` | Карта привычек на текущую неделю (`Пн–Вс`) |
| `/sleep` | Итоги дня: выполнено / не выполнено |
| `/del` | Удалить привычку |
| `/cancel` | Отменить текущий диалог |

## Формат данных

Все данные хранятся в `habits_data.json`:

```json
{
  "123456789": {
    "habits": [
      {
        "name": "Зарядка",
        "time": "07:00",
        "done_dates": ["2026-09-12", "2026-09-13", "2026-09-14"]
      }
    ]
  }
}
```

- `name` — название привычки;
- `time` — время напоминания (`null`, если не задано);
- `done_dates` — список дат (ISO `YYYY-MM-DD`), когда привычка была выполнена.

Благодаря такому формату **привычки автоматически «свежие» каждый день** — новая дата просто не входит в `done_dates`, пока вы её не отметите.



## Технологии

- **Python 3.10+**
- [**aiogram 3.x**](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram Bot API
- **FSM (Finite State Machine)** — для пошагового диалога добавления привычек
- **JSON** — простое и надёжное хранилище данных

## Безопасность

- Токен бота хранится **только** в переменной окружения `BOT_TOKEN`.
- `habits_data.json` содержит персональные данные — добавлен в `.gitignore`.
- Если токен случайно попал в коммит:
  1. **Немедленно отзовите** его в [@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот → API Token → Revoke.
  2. Сгенерируйте новый и подставьте через переменную окружения.
  3. Удалите токен из истории Git (BFG Repo-Cleaner или `git filter-repo`).
